## 2. 特征提取参数（定稿）

| 项 | 值 |
|---|---|
| 稳态窗 | `2.00–18.00 s`（16 s）。⛔ 不裁文件、不删首尾行，只在计算时取窗 |
| 去直流 | 窗内逐通道减均值（az 约 9.6 m/s² 是含 g 重力分量，不预先减 g） |
| Welch | 手写分段周期图平均：`nperseg=1024`、`noverlap=512`、`nfft=1024`、hann 窗、`fs=100` |
| 频率分辨率 | Δf = 100/1024 ≈ **0.0977 Hz** |
| **频带（改版）** | `0–1 / 1–3 / 3–6 / 6–12 / 12–25 Hz`（占比按 0–50 Hz 总功率归一化） |
| 通道 | `ax / ay / az / |a|` 四通道 |
| 每通道 12 维 | 5 个频带占比 + 主导频率 + RMS + 方差 + 峰值(abs max) + 峭度 + 峰值因子 + 零交叉率 |
| 特征总数 | 4 × 12 = **48 维**；输出 `data/features.csv` 共 **60 列**（12 元列 + 48 特征） |
| `nyq_warn` | 主导频率 ≥40 Hz 置 1，标注「可能为折叠峰」 |

⛔ **不再使用**此前 `B1 0–5 / B2 5–15 / B3 15–25 / B4 25–40 / B5 40–49` 那套。

## 3. 改版依据（实测，写进报告方法章节）

- `C1_R01` 稳态窗内 `|a|` 通道：`0–1 Hz` 占 **46.5%**、`1–3 Hz` 占 **28.4%**、`3–6 Hz` 占 **16.4%**，0–6 Hz 合计约 **91%**；`25–50 Hz` 仅 **0.7%**
- `C2_R01` 主导峰 `1.75 / 1.81 / 3.5 Hz`；`C3_R01` 主导峰 `1.75 Hz + 11.56 Hz` —— 工况可分性体现在低频带与 6–12 Hz，而非高频叶频
- 结论措辞：**「能量集中于 0–12 Hz，未观察到高频叶频，受传感器机械耦合与有效带宽限制」**

## 4. 报告里的四条硬限定

1. ⛔ 不写「识别出 C2 叶频为 XX Hz」；0–50 Hz 之外仍按采样定理折叠，`nyq_warn=1` 的组只作标注不作物理解释
2. ⛔ 不拿声学那份 64.6 Hz 叶频簇解释加速度频带能量：44.1 kHz 音频里的 64.6 Hz，在 100 Hz 加速度通道会折成 35.4 Hz，两套通道不可互证
3. 声学通道说明沿用统一口径：HarmonyOS 4 原生录音仅 MP3/AAC，留存 WAV 由格式转换得到（文件头 `Lavf58.42.100`），属**转码留痕而非原始序列**，不纳入 `data/raw/`、不参与 FFT 与分类指标；三/五份均无对齐敲击尖峰，不承担时间轴对齐
4. 少采、作废、混入派生风险全部照实写。**少采是瑕疵，造数是事故**
