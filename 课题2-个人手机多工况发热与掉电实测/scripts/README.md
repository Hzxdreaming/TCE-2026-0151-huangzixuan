# scripts/

本目录只放**提交前必跑**的扫描脚本，不含任何具体 SSID / 地名 / 设备名明文。

| 脚本 | 何时跑 | 期望 |
|------|--------|------|
| `scan_secrets.sh` | **`git add 课题2/` 之后、commit 之前，必跑** | 各扫描段无命中，图片 EXIF 全为 0 |

## 提交前必跑

在**仓库任意位置**执行都可以，脚本会自己定位仓库根：

```bash
cd <已有仓库>            # 仓库内已有课题10 等内容
git add 课题2/
bash 课题2/scripts/scan_secrets.sh
# 想连既有课题内容一起扫：bash 课题2/scripts/scan_secrets.sh --all
git commit -m "添加课题2: P30 Pro 四工况30分钟耗电与发热对比（24组采样，公开脱敏版）"
git push origin main
```

`git grep` 需要 `.git` 存在，所以要在已 clone / 已初始化的仓库里跑；本场景**不需要 `git init`**，也不要用 `git add .`（会卷进课题10 的本地改动）。脚本默认只扫 `课题2/` 子目录，既有课题内容不改动、不重扫。

## 为什么扫描式是「通用形态」

脚本查的是**模式**而不是具体词：

- 网络名后跟一串具体字符 → 未替换的 SSID（占位符含尖括号，不在字符类内，不会误报）
- 具体地名与院校 / 餐饮名的组合 → 未泛化的地址结构
- 水印标识后跟 10 位以上大写字母数字 → 防伪码（含裸码形式）
- 15 位连续数字、14~20 位连续十六进制 → IMEI / MEID / 序列号（上限避开文件名 hash 与校验值）
- 常见密钥前缀、令牌赋值、私钥头 → 密钥形态
- 设备名称后跟未打码的字母数字串 → 设备名残留

**含明文替换映射表的「从本地定稿重建公开副本」工具仅存放于本地，不入库** —— 否则规则表本身就成了公开仓里唯一残留的标识与地名，会让「统一替换」的声明失去严密性。若需新增证据材料后重跑脱敏，请在本地环境使用该工具，再跑本目录的扫描脚本验收。

## 若新增含正面人脸的照片

公开仓当前 3 张 JPG 已脱敏（P01 同框照人物为背面/侧后，无正面可识别人脸）。**新增任何含正脸的照片必须先做不可逆人脸模糊再入库**。公开仓的人脸一旦 `push` 无法收回 —— fork、爬虫、CDN 缓存会在几分钟内复制。
