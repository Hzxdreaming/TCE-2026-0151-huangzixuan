## 三个最容易踩的坑

**① 不要在 `课题2_公开仓库/` 里执行过 `git init` 后整个拷进来**
那会带进一个嵌套 `.git`，git 会把它记成 gitlink / 提示 submodule，`课题2-个人手机多工况发热与掉电实测/` 里的文件实际上没入库。若已 init 过，先删掉该目录里的 `.git` 再拷贝：

```bash
rm -rf 课题2-个人手机多工况发热与掉电实测/.git
git rm --cached 课题2 2>/dev/null   # 若已误加过一次
```

**② 别用 `git add .`**
会把课题10 本地尚未提交的改动一起卷进这次 commit。用 `git add 课题2-个人手机多工况发热与掉电实测/` 精确添加；扫描脚本的「附加 B」会列出任何意外触碰既有内容的路径。

**③ 根 `.gitignore` 优先级更高**
仓库根的忽略规则对**全仓**生效，`课题2-个人手机多工况发热与掉电实测/.gitignore` 改不了它。常见误伤规则：`*secrets*`（吞掉 `scan_secrets.sh`）、`*.csv`、`data/`、`*.jpg`。第 3 步的 `git check-ignore -v` 就是查这个；被吞了用 `git add -f` 兜底，或请谨慎地在根 `.gitignore` 加例外。
