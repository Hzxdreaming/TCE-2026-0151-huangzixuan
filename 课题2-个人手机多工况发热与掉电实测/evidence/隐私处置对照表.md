> 适用口径：**公开** GitHub 仓库。公开仓库的 `push` 不可逆 —— fork、爬虫、CDN 缓存、GitHub 历史记录会在几分钟内复制内容，事后转私有或删 commit 均无法收回。所有处置必须在**第一次 push 之前**完成。

本地定稿 SHA256：`1b5c5c6aefad8dbd39321bd0f191e595aac377bcc0923a8e66564419b22c912a`（不上传、不改动）。

**② 口径瑕疵一个字别删**

## 公开 vs 私有差异

| 项目 | 私有仓 | **公开仓（本仓库）** |
|------|--------|----------------------|
| 精确地址 | 可保留 | **必泛化** |
| 防伪码 | 可保留 | **必遮盖** |
| SSID | 可保留 | **必替换** |
| 正面人脸 | 可保留（授权后） | **必不可逆模糊** |
| 屏幕文字 | 可选 | **必模糊** |
| EXIF | 建议清 | **必清且校验为 0** |
| IMEI / MEID / 设备名 | **一律必打码**（与可见性无关，属设备唯一标识） | 同左 |
