# raw_data · 本校实地采样原始数据表

本目录按考核要求提供 **逐点原始采样记录**，与 `../data/课题2_24组采样数据.csv` 为**同一份文件**（SHA256 一致），保留 `data/` 是因为报告与脚本中的路径引用均指向它。

## 表格内容

- **24 行 × 21 列**：待机 / 短视频 / 导航·拍摄 / 游戏 四档，每档 6 行，每 5 分钟 1 行。
- 逐点记录：时间、校园点位、电量百分比、电池温度、四区温感（上部 / 摄像头区 / 下部 / 屏幕面）、整机温感、最热部位、环温、亮度、网络、同框照片编号、备注。
- 含派生列：五分钟掉电、累计掉电、最热部位——均为当场记录后的直接计算，未作平滑、插值或补齐。

## 如实保留的现场记录

以下不是脏数据，**不得因「不好看」删除**：

- P01 六行时间按用户确认补录为 `10:30 / 10:35 / 10:40 / 10:45 / 10:50 / 10:55`；备注中早期写下的 `档起10:50`、`0分钟基线:10:50` **原样并列保留**，未静默改写。两处口径的关系见 `../docs/课题2_V38_变更说明_校名写回与同框照入库.md`。
- `13:45 纸质 A4 表当场手写补认`、`按曲线横轴落位 / 状态栏差约 2 小时`、`掉电 5→0 台阶`、`39℃ 与 CPU 页 39℃ 数值巧合`、`大字与当前值 0~1℃ 刷新差`。
- 各档起始电量 `97 / 89 / 98 / 47 %` 不一致、P04 低于 60~90 % 起测区间；跨档只比掉电速率与温升幅度，不比绝对电量。
